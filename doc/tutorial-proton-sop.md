## 课程编排

| 章节 | 真实界面操作 | 对应原文 |
| --- | --- | --- |
| 01 分段升温与保温编排 | 逐个选择温度节点，设置 93、260、665°C 与 1、1、3°C/min；设置两段等待 7200s；展开实际计划 | 第 1 节 |
| 02 预处理与 OCV 放行判据 | 将三个 OCV 监测段分别改为 1800、7200、3600s；讲解气氛切换与人工放行关口 | 第 2 节及第 5 节异常处理 |
| 03 发电模式与四温度点配置 | 配置首组稳定时段、OCV、LSV 电位参考及 0.4V 终点、EIS 频率与幅值；复核其余温度块与回温，展开计划 | 第 3、5 节 |
| 04 电解模式与四温度点复核 | 解释湿度切换；首个 650°C 稳定 1800s，LSV 终点改为 1.5V；核对全部温度块、EIS 与回温 | 第 4、5 节 |

模板属于课程初始状态，不把预置节点伪装成用户刚完成的操作。升温章的目标值、速率和等待时长在播放中通过真实输入框填写；发电与电解章的其余温度块按 SOP 预置并逐块讲解，首组 LSV/EIS 从普通默认参数开始演示修改。

## 参数映射

| 原文要求 | 教学表示 |
| --- | --- |
| 25→93°C，1°C/min；保温120min | 温度93、速率1，随后等待7200s |
| 93→260°C，1°C/min；保温120min | 温度260、速率1，随后等待7200s |
| 260→665°C，3°C/min | 温度665、速率3 |
| 升温及保温610min；再稳定30min | 理论10h10min与10h40min分开讲解，不把软件估算当作恒定实测耗时 |
| 665°C稳定30min；预处理2h；50sccm H₂后1h | 三个OCV教学时段1800、7200、3600s |
| 预处理气体 | 燃料侧5sccm H₂+45sccm N₂；空气侧50sccm air，明确人工确认 |
| 切换气氛 | 燃料侧50sccm H₂、空气侧50sccm air；稳态OCV>1V后燃料侧100sccm H₂ |
| 测试温度点650、600、550、500°C | 显式建立四个顺序测试块，不用参数不变的普通循环冒充变温扫描 |
| 每温度点稳定15min；正式OCV1min | 稳定OCV900s与正式OCV60s分为两个节点 |
| 电解模式切换后650°C至少稳定30min | 首组稳定1800s，其余温度点900s；至少30min不等于自动认定已稳定 |
| LSV从OCV开始 | 起点参考`ocv`，起点偏移0V；终点参考`absolute` |
| 发电0.4V；电解1.5V | `end_voltage`分别为0.4与1.5 |
| EIS 0.1Hz–1MHz；20mV；OCV无偏压 | 低频0.1、高频1000000、振幅0.02V，直流偏置关闭 |
| 发电气氛 | 燃料侧H₂+3%H₂O；空气侧air+3%H₂O |
| 电解气氛 | 燃料侧H₂+3%H₂O；空气侧air+20%H₂O |
| 两种模式完成后升回650°C | 各章末尾均包含独立回温节点 |

温度节点的初始稳定时间设为0，教学用后续等待或OCV时段明确表示稳定时间，避免额外叠加默认稳定时间。此字段在现有属性栏中只读，教程不假装可以通过输入框编辑它；0 是明确的教学前置配置。真实执行仍需核对炉体的达到目标与稳定判据及正式工作流配置。

## 人工关口与未给定参数

1. **OCV判据不能由时长替代。** 原文规定稳态OCV>1V后放行，不到1V暂停报告；恰好1V未明确，不默认放行。教程不创建未验证的自动条件分支。
2. **连续OCV是原文要求，尚未以完整实验验证。** 分段OCV节点仅用于教学时段映射，不保证跨气氛切换和LSV/EIS阶段的无缝监测。串行计划预览不能证明连续监测要求已满足，正式使用前需确认监测实现与实验要求。
3. **气路与加湿需要确认。** 原文没有设备地址、气路映射、阀位或加湿控制命令，教程不猜测MFC地址，也不伪造湿度控制组件。
4. **数值缺口保留为缺口。** 原文未提供降温/回温速率、LSV扫描速度或时长、采样间隔、电流保护限值、EIS频点与周期设置以及振幅口径。界面继承的默认值不是SOP要求。实际使用前由实验负责人补齐并验证设备频段能力。
5. **模式切换优先满足专门规定。** 初次进入发电测试使用第3节的15min稳定示例；若是发电/电解之间切换，按第5节在650°C重新稳定30min，不能沿用普通温度点15min。电解章首个650°C已按30min处理；后续温度点按15min。
6. **本课程停在配置与核对。** 不点击运行，不以已有单节点OCP回放冒充复杂实验数据。实际异常按原文停止后续步骤并报告。
