# 执行错误分阶段提示与诊断导出

状态：已完成（2026-10-08）。范围：用户授权区分温度节点命令下发、状态确认和目标等待失败，增加一键本地诊断导出，并提供修改前后可视化对比。旧版对比基线为 2.11.2；用户未保存原始报错，对比使用可复现故障样例，不能作为另一台电脑的历史截图。

修改前：执行器将异常转为 error 字符串，通知标题统一“执行失败”；通知中心直接展开 details 原始数据。现有设备运行时快照、命令日志、执行步骤结果及生命周期事件作为诊断来源。不改变模拟独立分支，不发送邮件或外部日志，不修改用户真实设备状态。

修改后：共享契约定义结构化失败（阶段、中文标题/说明、启动命令结果、建议和原始原因）及导出响应；后端在对应阶段生成失败事实，现有步骤 JSON 保存详情，通知中心显示中文错误卡片、本地导出按钮和目标/最近温度/等待时长。首条配置写入失败不会冒充启动命令结果未知；启动尝试后缺失回执才记未知。等待目标温度超时与等待阶段读取状态失败分开；取消时停止命令失败保留真实错误，普通取消原样处理。历史执行在重置/重启后仍能获取已保存的失败；活动设备状态注明是导出时状态，不冒充故障时状态。不自动重试设备写命令，不将内部寄存器或身份字段作为用户操作要求。

版本：2.11.2 → 2.12.0，MINOR；新增用户可见诊断能力和只读导出接口。通过 VERSION 同步各版本字段，更新 CHANGELOG；不改 API 主版本或数据库结构，无需数据库迁移。
