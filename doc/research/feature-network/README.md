## 打开与使用

[打开交互式功能全景图](feature-network.html)。HTML 自包含，可直接在浏览器离线打开。

沿“准备与配置 → 编排与预览 → 执行与控制 → 查看与导出”查看现有能力。点击模块展开，点击功能查看用途、入口、关联功能、源码位置和验证边界。支持搜索、拖动画布、滚轮缩放、键盘 Enter/Space、收起模块和总览。内部实现层默认隐藏，勾选后显示。

图含 **33 个模块、228 个能力条目**，其中 8 个模块属于内部层；逐项覆盖 **18 种可见节点、2 个自动测量边界和 17 门教程**。条目是组织后的功能与实现能力，不是 228 个独立界面或全部通过的测试。

## 文件与重绘

| 文件 | 用途 |
| --- | --- |
| `feature-network.html` | 最终离线交互图 |
| `graph.json` | 人工组织后的模块、能力、关系与验证标记 |
| `source-audit.json` | 三组当次源码调查证据；不是全部候选问题的最终判定 |
| `coverage.json` | 文件覆盖与源码 SHA256 |
| `verification.json` | 接口调用摘要、UI 操作、导出验证与截图哈希 |
| `findings.md` | 已确认问题、现状边界、排除项 |
| `network.template.html`、`render.mjs` | 可维护模板与生成器 |
| `screenshots/` | 当次真实浏览器截图 |

在项目根目录执行：

```powershell
node doc/research/feature-network/render.mjs
```

生成器从本目录 `graph.json` 与模板生成 HTML，不自动重读产品代码或更新功能结论。以后复核应先更新结构化证据、分析 SHA 和验证边界，再重绘。原始临时验证脚本、实验数据与 MCP 会话位于已忽略的 `.codex-run/feature-network/`，不提交。
