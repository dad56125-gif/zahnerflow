## 已确认的问题

1. **合法基础路径被界面拒绝，提示与正则不一致。** `apps/frontend/src/components/user/UserSettingsModal.tsx:186` 只允许 ASCII 字母、数字及 `\\/:_-`，空格和中文不允许；`:208` 提示却只列 `<>"|?*`。实际使用包含 `Code project` 的隔离路径，UI 显示无效字符，后端保存接受。项目/样品的英文数字下划线约束是另一项明确规则，未混为同一问题。
2. **运行提示包含 F5，未接入快捷键。** `apps/frontend/src/components/Toolbar.tsx:388` 标注“运行 (F5)”；当前前端无 F5/KeyF 监听。实际点击运行可用，快捷键只作源码不一致登记。

## 当前能力边界

- **流程是有序步骤。** 支持嵌套循环；工作流块仅单层，嵌套明确拒绝。画布连线不支持任意拓扑；双击处理为空。工作流在启动时按指纹自动归档，没有独立保存、导入/导出定义或剪贴板入口。报告导出是另一项能力。
- **暂停/恢复属于 API 与 CLI。** GUI 没有对应按钮。暂停阻止进入下一步骤，不冻结当前等待或测量；取消不可中断 EIS 需要等待当前测量返回。
- **实时缓存与历史报告不同。** 刷新重建前端 Map，连接握手不回放测量历史；刷新后的实时表可为 0，报告从归档 CSV 恢复曲线。实际新运行后 OCV 表显示 4 点，历史报告含 OCV 4 点及 Nyquist 30 点。
- **模拟输出不是仪器格式验收。** `apps/python_backend/devices/zahner/simulator_device.py:139-143` 的 `.ism` 是文本占位，真实数据格式未验证。模拟设备响应不证明真机稳定性或测量准确度。
- **教程写操作隔离。** 17 门课程使用真实组件和录制数据；展开预览与 ETA 的两个只读调用使用真实 Planner，其他教学请求不创建真实执行或操作设备。四节 SOP 以流程配置复核为主。
- **个人偏好没有云同步。** cloud 分组显示背景与头像，契约中的云字段没有界面/服务入口，不作为已实现用户功能。
- **运行时允许设备连接/控制入口。** 当前设计没有规定设备与执行互斥；连接代次与锁处理并发事实。未在活跃执行中做改变设备的破坏性验证，不列为缺陷。
- **通知与邮件限制。** 通知列表不持久化；未读标记没有读取调用方；警告邮件限流为进程内状态，取消不发邮件。实际 SMTP 未测试。
- **自动边界不可选作起点。** startup/shutdown 为后端插入，不在可见库中，展开视图不允许从自动边界开始。
- **导出验收有范围。** HTML/诊断/PDF 内容生成成功；浏览器文件落盘与 PDF 逐页排版未验证。具体证据见 `verification.json`。
