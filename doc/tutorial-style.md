# 新手教程样式定稿

状态：已确认的教学视觉基线。版本：2.3.5。确认日期：2026-09-20。归属：前端教学功能。

本次确认保留真实界面上的压暗、高亮、演示光标和教学控制，删除局部放大。后续课程沿用本规范；增加课程只增加步骤与内容，不自行引入新的教学外壳、视觉效果或控件样式。架构与数据隔离以 [.memory/design.md](../.memory/design.md) 的 `[前端-微教程]` 为准。

## 1. 入口与目录

- 入口在顶栏“新建用户”按钮右侧。
- 目录使用现有 `SplitPaneModal` 与 `SplitPaneModalItem`，与实验记录弹窗共享外壳、标题、关闭按钮、列表选中态和开关动画。
- 左侧按分类列出课程，不显示步骤或阶段数量；右侧以时间线展示总结性阶段标题和解释，从课程 outline 读取。每门课合并为 2–4 个学习阶段，不逐项描述点击、输入、关闭等操作。实机演示仍保留完整 steps。编号以圆圈呈现、数字居中，相邻圆圈以竖线连接，末步后不延伸连线。
- 教程弹窗最大 820×660px，受 92vw 和 82vh 限制；桌面侧栏约占 26%，两侧内容独立滚动。
- 步骤列表沿用共享弹窗右栏滚动区域；切换课程回到顶部，保留“开始界面演示”按钮。
- “开始界面演示”沿用 `btn btn--sm btn--primary is-prominent`。开始后关闭目录，完整演示在当前应用界面中进行。

## 2. 演示视觉参数

下表为 CSS 像素和源码颜色值，仍受项目整体显示比例影响。业务组件继续使用自身共享样式与主题令牌。

| 元素 | 固定规则 |
| --- | --- |
| 真实控件 | 保持原始尺寸、样式和布局；不写入教学缩放，不显示镜像窗或局部放大窗 |
| 背景压暗 | 目标高亮框外使用 62% 黑色遮罩；没有有效目标时撤去高亮及其遮罩 |
| 高亮框 | 真实目标边界向外扩 5px，2px `#469fc4` 描边，10px 圆角，18px `#469fc470` 外光晕 |
| 高亮跟踪 | 逐帧读取真实位置；不使用拖尾过渡；菜单关闭、隐藏、卸载或被业务浮层遮挡时立即清除 |
| 演示光标 | 28×36 SVG 白色箭头，`#182633` 描边；移动使用 700ms ease-in-out |
| 按压提示 | 光标处 34×34 圆环，3px `#469fc4` 描边 |
| 拖拽影像 | 仅拖动期间克隆真实节点画面，85% 不透明度；不创建业务组件或另一套节点样式；结束或取消后移除 |
| 说明面板 | 共享玻璃面板、`--glass-bg-active` 背景、`--glass-border` 边框；12px 圆角、16px 内边距 |
| 说明文字 | 步数与课程名 12px；标题 17px；正文 13px、1.7 行高；颜色沿用项目主题令牌 |
| 控制按钮 | 共享 `btn--sm`；重播与下一步使用次级样式，暂停/继续使用主样式；间距 8px、顶部间距 14px |
| 顶部状态条 | 水平居中，位于应用标题栏下 12px；12px 圆角，内边距 8px 14px，12px 文字；含教学状态说明及退出按钮 |

不保留局部放大的实现、定时镜像刷新或占位区域；也不以 CSS scale 放大真实控件。教学光标和高亮只是标注，不代替实际输入目标。

## 3. 定位与层级

- 教学控制层固定覆盖当前应用，层级为 22000；标注不接收鼠标事件，教学按钮可操作。
- 控制面板处在遮罩上方，避免被压暗。演示光标处在标注层内的上层。
- 说明面板默认距左侧 24px、底部 90px，宽度 `min(460px, 100vw - 48px)`。
- 面板在左下、右下、顶部居中三个位置中选择与目标重叠最少的位置；目标预留 12px 避让距离。顶部候选位置为距视口顶部 80px。
- 高亮必须跟随真实 DOM 的位置与可见性，不能记住已关闭下拉菜单的旧矩形。
- 尊重 `prefers-reduced-motion`，关闭光标移动过渡。

## 4. 教学交互

- 同一应用实例、同一真实组件和业务处理链，教学仅切换隔离数据；不新开前端，不挂载第二个 App，不使用 iframe。
- 点击、输入、失焦、拖拽、右键、长按都通过真实控件处理；检查实际结果后再推进步骤。
- 用户对业务界面的物理输入在教学期间被拦截，教学控制仍可用。暂停在当前原子操作结束后生效，不留下按住的指针或半次输入。
- 隐藏页面时暂停；Tab 在教学控制之间移动；Escape 退出。
- 重播重置教学会话数据；退出释放输入、关闭教学打开的浮层、清除标注并恢复原工作区。
